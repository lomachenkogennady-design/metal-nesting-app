# Metal Nesting & Quoting App 🛠️

Кроссплатформенное приложение (Android / Windows / macOS) для автоматизации раскроя листового металла, расчета стоимости резки и формирования Коммерческих Предложений (КП).

## 🚀 Основные возможности
- **Импорт и обработка DXF:** Автоматический расчет длины реза, площади и количества врезок.
- **Интерактивный раскрой (2D Nesting):** Оптимизация укладки деталей на листах с минимальным процентом отходов.
- **Калькулятор стоимости:** Расчет материалов, длины реза, пробивок, доп. работ и наценок.
- **Автогенерация КП:** Формирование готового PDF с графическими картами раскроя для отправки клиенту в 1 клик.
